# mon_site

Ce dépôt contient le portfolio personnel de Yael. Il est servi via GitHub Pages à l'URL :

https://yael2816.github.io/mon_site

Structure du dépôt :
- index.html — page principale du portfolio
- assets/ — feuilles de style, images
- projects/ — pages individuelles pour chaque projet

Comment ajouter un projet :
1. Créez un nouveau dossier `projects/nom_du_projet/`.
2. Ajoutez un `index.html` dans ce dossier avec la description et les liens.
3. Ajoutez une carte dans la section "Projets" de `index.html` (ou je peux le faire pour vous).

Si vous voulez, je peux :
- Ajouter un formulaire de contact fonctionnel (Formspree, Netlify Forms, ou autre).
- Ajouter un CV (PDF) et une page "Expérience".
- Mettre en place un workflow GitHub Action pour déployer automatiquement (déjà fait par Pages sur push).

Dites-moi la prochaine action que vous souhaitez.
